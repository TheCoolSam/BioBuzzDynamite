# Pedro AutoTune procedures

These files are copied unmodified from the official Pedro Pathing Quickstart
(https://github.com/Pedro-Pathing/Quickstart, `pedro/procedures/`). They are the tuners that the AutoTune web page
(http://192.168.43.1:10158) runs. See that repository for the license.

Do not edit them. To update, re-copy from the Quickstart that matches the Pedro version in
`build.dependencies.gradle`. The tuners are registered in `../Tuning.java`; results are pasted into `../PedroTuned.java`.
Steps: `doc/PEDRO_AUTOTUNE_GUIDE.md`.
